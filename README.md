# IntruSense: AI-Powered Hybrid Intrusion Detection System (IDS)

IntruSense is an end-to-end AI-powered Intrusion Detection System designed to detect both **known attacks** using supervised machine learning and **unknown / zero-day attacks** using a deep-learning Autoencoder anomaly detector.

This project combines:

- **Supervised ML classifiers** (Random Forest, XGBoost)  
- **Unsupervised deep learning** (Autoencoder)  
- **Hybrid Decision Engine** (XGB + AE)  
- **Real-time streaming attack simulation with IP/Port logs**  
- **Visualization suite**  
- **Docker support**  
- **Full automation via batch script**  

IntruSense supports both **CICIDS2017** and **NSL-KDD** datasets.
